# Contribuir

Proponha módulos com objetivo, pré-requisitos, explicação, passos, entrega, critério de aceite e fontes primárias. Recursos devem conter atividade prática, origem e data de consulta. Casos devem ser sintéticos, com alternativas plausíveis, justificativa do gabarito e vínculo a um módulo.

Não inclua dados pessoais, segredos, conteúdo copiado sem licença ou alegações de eficácia sem evidência. Diferencie roteiro, laboratório executável e simulação por regras.

Edite src/data.js e o guia Markdown correspondente. Execute npm test e npm run build. Atualize contagens no README quando alterar o catálogo. Abra PR explicando o problema, mudança, validação e limitações.
